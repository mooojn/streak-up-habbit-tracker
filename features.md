# StreakUp App: Improvements and New AI Features

Based on the current architecture of StreakUp and its integration with the local AI model (via `server.py`), here are several feature suggestions and improvements that can elevate the app from a simple habit tracker to a smart, personalized productivity assistant.

## 🤖 AI-Powered Features (Leveraging `server.py`)

Since you already have endpoints for `/api/generate` and `/api/chat` using Ollama, you can seamlessly integrate these into the Android app.

### 1. AI Accountability Coach (Chat Interface)
- **Feature:** Add a new "Coach" tab in the Bottom Navigation (`DashboardActivity`). 
- **How it works:** Users can chat with the local AI acting as an accountability partner. They can ask for advice on how to stop procrastinating, how to build a specific habit, or just talk about their daily struggles.
- **Implementation:** Use the `/api/chat` endpoint. Maintain the conversation history in the app's `SharedPreferences` or a local database so the AI remembers the context.

### 2. Smart Habit Breakdown
- **Feature:** When a user wants to add a complex habit (e.g., "Get fit" or "Learn Spanish"), the AI breaks it down into actionable daily micro-habits.
- **How it works:** In the `AddHabitFragment`, add a "Help me define this" button. The app sends the user's broad goal to `/api/generate`, and the AI returns 3-5 specific, measurable daily habits (e.g., "Do 10 pushups", "Study Spanish for 15 minutes").

### 3. Personalized Daily Motivation & Insights
- **Feature:** Replace static greetings in the `ProfileFragment` with a daily personalized motivational message generated by the AI.
- **How it works:** Send the user's current streak data (e.g., "User has a 5-day streak on Reading but missed Workout yesterday") to `/api/generate`. The AI can generate an encouraging message tailored to their actual progress.

### 4. AI-Generated Habit Reminders
- **Feature:** Instead of a generic "Don't forget your habit" notification, use the AI to generate dynamic, contextual reminder texts.
- **Implementation:** In `StreakReminderWorker.kt`, fetch a short reminder text from the local server before triggering `StreakReminderNotifier`.

## 🚀 General App Improvements

### 1. Cloud Sync & Backup
- **Current State:** Data is currently stored locally using `SharedPreferences` in `HabitRepository.kt`.
- **Improvement:** Migrate to a local SQLite database using **Room**, and add cloud synchronization (e.g., Firebase Firestore or a custom backend) so users don't lose their streaks if they uninstall the app or switch devices.

### 2. Advanced Statistics & Analytics
- **Current State:** The app has a basic monthly heatmap (`TrackerFragment`).
- **Improvement:** Add detailed analytics such as:
  - Longest streak ever achieved.
  - Completion percentage for the week/month.
  - Best day of the week for habit completion.

### 3. Habit Categories & Sorting
- **Current State:** All habits are displayed in a single list in `HabitsFragment`.
- **Improvement:** Allow users to tag habits (e.g., Health, Work, Study) and filter the dashboard based on these categories. Allow manual reordering of habits using drag-and-drop.

### 4. Time-of-Day Reminders
- **Current State:** Reminders are scheduled universally around 20:00 local time via `StreakReminderScheduler.kt`.
- **Improvement:** Let users set individual reminder times for specific habits (e.g., Morning routine at 7:00 AM, Reading at 9:00 PM).

### 5. Gamification (Badges & Levels)
- **Feature:** Introduce a leveling system. Completing habits gives XP, and reaching certain streak milestones unlocks visual badges on the user's profile.

## Next Steps for Implementation
To start implementing the AI features, you will need to:
1. Add networking libraries like **Retrofit** or **OkHttp** to your `app/build.gradle.kts`.
2. Create an `ApiRepository` in your Android app to communicate with `http://<your-local-ip>:5050/api/...`.
3. Ensure the Android app handles network calls asynchronously (using Kotlin Coroutines) to keep the UI smooth.
